# Fluxa — marca final (Monograma fluido)

Proposta A, escolhida e refinada. Só as cores reais da v1.0.1.

- `svg/` — contornos preenchidos, sem fonte, máscara ou traço.
  - `simbolo-*` e `logo-*`: petróleo, creme, mono preto e mono branco, com fundo transparente.
  - `icone-*`: petróleo, creme, noite e mono. Quadrado cheio; a plataforma aplica a máscara. Serve também de avatar.
  - `favicon.svg`: cantos próprios e símbolo maior.
- `png/` — os mesmos arquivos. Ícones em 1024 × 1024.
- `materiais/`
  - `github-social-1280x640.png`
  - `linkedin-banner-1584x396.png`: canto inferior esquerdo livre para o avatar.
  - `linkedin-post-1200x1200.png`
  - `portfolio-capa-1600x1000.png`
- `tools/` — `mark.py` (geometria, inclusive a dos vetores Android) e `build.py` (gera tudo).

## Uso

| | |
| --- | --- |
| Petróleo | `#14414D` |
| Creme do símbolo | `#FFFDF7` |
| Papel | `#F6F2EA` |
| Noite (splash) | `#0E171B` |

- Margem livre: pelo menos a largura de uma haste em volta do símbolo.
- Abaixo de 20 px a fenda some e o F continua legível.
- Não aplicar gradiente, sombra, contorno ou rotação.

As telas dos materiais são capturas reais da 1.0.1 com dados sintéticos, sem a barra de status do emulador. A 1.0.2 não muda nenhuma tela. Não houve pesquisa de marca registrada.
