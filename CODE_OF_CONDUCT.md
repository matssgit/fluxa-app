# Código de Conduta

O Fluxa é um projeto pequeno e aberto. Queremos que qualquer pessoa possa participar com segurança, independentemente de experiência, identidade ou origem.

## Esperado

- Tratar as pessoas com respeito e boa-fé.
- Criticar ideias e código, não pessoas.
- Aceitar que nem toda sugestão será adotada, e explicar o porquê quando for o mantenedor.
- Proteger a privacidade alheia: não publicar dados pessoais ou financeiros de ninguém.

## Não aceito

- Assédio, insultos, discriminação ou linguagem sexualizada.
- Ataques pessoais, provocações e perseguição.
- Divulgar informações privadas de outra pessoa sem permissão.
- Spam e autopromoção sem relação com o projeto.

## Aplicação

O mantenedor pode editar ou remover comentários, fechar discussões e bloquear participantes que descumpram este código. Para relatar um problema de conduta, use o relato privado na aba **Security** do repositório, indicando que se trata de conduta.

Este código se inspira no [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.
